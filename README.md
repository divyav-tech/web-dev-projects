## 🚀 Running the Projects

Most projects are built using plain HTML, CSS, and JavaScript, so they don't require any frameworks or complicated setup.

1. Clone the repository:

```bash
git clone https://github.com/divyav-tech/web-dev-projects.git
```

2. Open the project you want to explore.

3. Open its `index.html` file in a browser.

For a better development experience, you can also use **VS Code with Live Server**.
